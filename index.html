AI Agent 企业知识助手

独立个人项目 ｜ 2026.09 – 至今 ｜ 项目链接：github.com/Heibaixiong1118/ai-agent-study
端到端 · 容器化部署

面向企业内部制度查询场景，独立设计并实现端到端知识问答 Agent：用户通过 API 提问后，本地大模型生成结构化决策， 自主判断直接回答或调用检索工具，从本地制度文档中取证后作答；全链路容器化、可一键部署。

  • 设计 JSON 结构化决策协议，实现「模型决策 → 工具分发 → Observation 回传」多轮循环，设 4 轮上限防止死循环。
  • 实现完整 RAG 链路：文档读取切分 → Embedding 生成 → ChromaDB 持久化索引 → 按问题检索相关片段。
  • 开发 rag_search、text_length 工具及统一工具分发器，基于结构化 JSON 决策执行调用。
  • 用 FastAPI 实现 POST /agent 问答接口，Pydantic 校验请求，Uvicorn 运行服务。
  • 编写 Dockerfile 与 Compose：ChromaDB 命名卷持久化，经 host.docker.internal 访问宿主机 Ollama。
  • 以 MCP Python SDK 实现独立 Client / Server 问候工具示例，验证工具发现与调用流程。
